# tagged_tape organizer package

Run the official solver against the participant binary:

```sh
python3 solve.py ../for_prob/tagged_tape
```

Then re-substitute the printed flag:

```sh
python3 solve.py ../for_prob/tagged_tape | ../for_prob/tagged_tape
```

`DESIGN.md`, `WRITEUP.md`, `HINTS.md`, and `UNINTENDED.md` contain private organizer material and must not be distributed.
