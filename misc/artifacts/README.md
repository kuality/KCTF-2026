# 최종 결과물 (사람이 결론을 눈으로 확인하는 파일들)

각 문제에서 **플레이어가 최종적으로 마주하는 산출물** 을 실물로 추출해 두었다.
현재 커밋된 배포물(`dist/*.zip`) 기준이며, 레퍼런스 솔버가 도달하는 바로 그 결과다.

정답을 담고 있으므로 배포물에는 포함하지 않는다.

---

## `01_residual_fragment.png` — 문제 1이 남기는 그 1장

OCR 파이프라인이 조각 410장을 처리하면 **409장은 자동 복원되고 1장만 남는다.**
그 1장이 이것이다 (원본 파일명 `59d29943.png`, 인덱스 83).

tesseract 는 어떤 전처리로도 이 저대비 조각을 못 읽지만, **사람 눈에는 또렷하다:**

```
AGD | NC4KCBKYGYRCSOENDEOHCYGW | RDB
```

이게 이 문제의 요점이다. AI 가 410장을 1장으로 줄이고, 마지막 1장은 사람이 10초면
읽는다. 인덱스 `AGD` 는 정답 인덱스 83과 일치하고, 이 한 줄을 채우면 ZIP 이 복원되어
`KCTF{0cr_p1p3l1n3_b34ts_th3_shr3dd3r}` 가 나온다.

## `02_hijack_email.eml` — 문제 2가 특정하는 진짜 메일 1통

600통 중 그래프 불변식으로 유일하게 걸러지는 스레드 하이재킹 메일이다
(원본 파일명 `0455.eml`). 사람이 봐야 할 핵심:

```
From: IT Helpdesk <helpdesk@norite-systerns.com>   ← rn ≠ m  호모글리프!
To:   (내부 직원 3명, 전원 @norite-systems.com)
Subject: Re: Kestrel 접근 권한 정리          ← 내부 스레드에 답장으로 끼어듦
Auth: spf=pass dkim=pass dmarc=pass          ← 위조 도메인은 공격자 소유라 인증 통과
Spam: 0.1                                     ← 필터를 통과했다
첨부: VPN_Cert_Renewal.html                   ← 난독화된 자격증명 탈취기
```

정상 도메인은 `norite-syste`**`m`**`s.com`, 이 메일은 `norite-syste`**`rn`**`s.com` 이다.
사람 눈엔 거의 안 보이지만 문자열 비교엔 100% 걸린다 — 이게 문제의 교훈이다.
첨부의 난독화를 풀고 조상 Message-ID 체인을 키로 복호하면
`KCTF{thr34d_h1j4ck_h1d3s_1n_th3_gr4ph}` 가 나온다.

## `03_decrypted_result.txt` — 문제 3의 교차추론 결과물

네 문서에서 각각 한 조각씩 뽑아 조립한 키로 복호한 최종 결과다.
어느 단일 문서에도 답이 없고, 4개를 전부 조인해야 나온다.

파일 안에 각 조각의 출처(리포트/샌드박스/IOC/트래픽)와 조립 과정, 그리고
복호 결과 `KCTF{cr0ss_d0c_c0rr3l4t10n_1s_th3_j0b}` 가 정리되어 있다.
